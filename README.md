# auto_recsys: ручной FE против автоматической генерации признаков (KION)

Ранжировщик LightGBM над кандидатами Popular + ItemKNN на данных MTS KION. Сравниваются сильный ручной feature engineering и четыре версии автоматической генерации признаков (V1–V4). Все пайплайны обучаются, отбираются и проверяются на одном сплите: 20 000 пользователей для обучения, 40 000 для валидации и 40 000 для теста.

## 📄 Полный отчёт: [report.pdf](report.pdf)

## Данные

MTS KION, полный архив `data_original.zip` (~79 МБ, 5.48 млн взаимодействий, метаданные пользователей и объектов) из репозитория [irsafilo/KION_DATASET](https://github.com/irsafilo/KION_DATASET), закреплённый на коммите и проверяемый по SHA-256 (оба значения в `config.json`). Сами данные в репозиторий не входят, скрипт скачивает их в `data/raw/`:

```bash
python scripts/download_data.py
```

`run.py` тоже скачивает архив сам, если его нет. Отдельный `interactions.csv.zip` из того же репозитория обрезан, поэтому используется только полный архив.

`data/excluded_users.csv` — 10 000 пользователей, на которых велась ранняя разработка. Они исключаются до разбиения на блоки, поэтому тестовые пользователи нигде раньше не использовались. Без этого файла сплит не совпадёт с отчётом.

## Воспроизведение

Нужны Python 3.12+ и `curl`.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

Полный прогон всех пайплайнов в отчёте занял около часа на 8 потоках и до 14 ГБ RAM. Результаты пишутся в `results/unified/` (каталог никогда не перезаписывается): `metrics.csv` (валидация и тест, LambdaRank и binary), `contrasts.csv` (парный bootstrap по пользователям), `selection/` (что выбрал каждый генератор), `feature_sets.json`, `timings.json`, модели.

Пайплайны можно запускать по отдельности на том же сплите. Все обучения детерминированы и не зависят друг от друга, поэтому цифры совпадают с полным прогоном:

```bash
.venv/bin/python run.py --pipelines manual --output results/manual
.venv/bin/python run.py --pipelines v1 --output results/v1
.venv/bin/python run.py --pipelines v2 --output results/v2
.venv/bin/python run.py --pipelines v3 --output results/v3
.venv/bin/python run.py --pipelines v4 --output results/v4   # V4 строится поверх V2 и сам запускает поиск V2
```

Контрасты считаются только для тех пар, обе стороны которых есть в запуске (например, «V2 − ручной» нужен `--pipelines manual v2`). Быстрая проверка, что всё работает, на маленьких блоках:

```bash
.venv/bin/python run.py --block-size 1000 --seeds 1 --bootstrap-repeats 50 --max-trees 60 --patience 10 --output results/smoke
```

## Протокол

- **Задача:** для пары (пользователь, объект) на момент cutoff предсказать, появится ли запись в следующие 7 дней. Признаки считаются только по строкам с `last_watch_dt < cutoff`.
- **Пользователи:** случайная перестановка (seed 2026) пользователей с историей, блоки по 20 000. Обучение — блок 1, валидация — блоки 2+3, тест — блоки 6+7.
- **Даты:** обучение на cutoff 12.07, 19.07, 26.07, 02.08; валидация 09.08; тест 16.08.
- Генераторы обучаются только на истории обучающих пользователей до 12.07. Все выборы (окна и семейства V2, подмножество формул V3, семейства V4, early stopping, калибровка Платта, абляции) делаются только на валидации.
- Наборы признаков и контрасты фиксируются в `plan.json` до загрузки тестовых пользователей, тест открывается один раз.

## Структура

| Путь | Что там |
| --- | --- |
| `run.py` | точка входа, выбор пайплайнов |
| `recsys/study.py` | единый протокол: сплит, поиск каждого генератора, финальные модели, тест, bootstrap |
| `recsys/common/` | загрузка KION и даты (`data.py`), кандидаты Popular + ItemKNN (`candidates.py`), NDCG@10 / Recall@10 (`metrics.py`), проверки отсутствия будущего (`contracts.py`) |
| `recsys/manual/` | ручной пайплайн: признаки (`features.py`, 66 признаков) и группы для абляций (`groups.py`) |
| `recsys/autogen/v1_schema.py` | V1: агрегаты из схемы таблиц с фиксированными окнами |
| `recsys/autogen/v2_grammar.py` | V2: грамматика V1 + семейства dynamics / affinity / segments, поиск окон и семейств |
| `recsys/autogen/v3_formulas.py` | V3: синтез типизированных формул (затравки, мутации, attribute lift) |
| `recsys/autogen/v4_graph.py` | V4: графовые семейства поверх V2 (co-visitation, недавний co-visitation, SVD, фильтрованная популярность) |
| `scripts/download_data.py` | загрузка и проверка архива KION |
| `config.json` | кандидаты, окна ручных признаков, гиперпараметры LightGBM, закреплённый источник данных |
| `report.pdf` | отчёт |
